# Recursos y videos de refuerzo

Lista curada de material para que los estudiantes **refuercen por su cuenta entre clases**. En cada
clase se recomienda el recurso que corresponde al tema. No reemplazan la clase: la complementan.

> Idea: en clase vemos el concepto y lo practicamos; en casa el estudiante ve el video para afianzar
> y de paso adelantar. Todos los recursos de abajo son **gratis y en español**.

---

## 📚 Documentación de referencia (fuentes de confianza)

Para **consultar** mientras programan (no para memorizar). Estas son las buenas:

| Tema | Referencias recomendadas |
|------|--------------------------|
| **General / oficial** | **MDN** — `https://developer.mozilla.org/es/` (la referencia oficial) |
| **HTML** | **lenguajehtml.com** (Manz) · **web.dev/learn/html** (`?hl=es`) |
| **CSS** | **web.dev/learn/css** (`https://web.dev/learn/css?hl=es`) · **lenguajecss.com** (Manz) · CSS-Tricks |
| **JavaScript** | **javascript.info** (el más completo) · **lenguajejs.com** (Manz) · **jscamp.dev** (midudev) |
| **Compatibilidad** | **caniuse.com** — ¿funciona en todos los navegadores? |

> ⚠️ **Evita W3Schools:** aparece mucho en Google, pero a veces trae información **desactualizada o
> imprecisa**. Prefiere las de arriba (MDN, web.dev, la familia *lenguaje\*.com* de Manz, javascript.info).
>
> 💡 El **asistente de IA** sirve para dudas puntuales y para que te **expliquen**; la documentación es
> para la fuente de verdad.

## 🎥 Videos por tema

### HTML — Clase 02
**Curso COMPLETO de HTML GRATIS desde cero: SEO, semántica y más**
https://www.youtube.com/watch?v=3nYLTiY5skU

Cubre estructura de una página, etiquetas, HTML semántico y buenas prácticas de SEO. Ideal para ver
entre la Clase 02 (HTML) y la Clase 03 (CSS).

### CSS — Clase 03
**CURSO DE CSS COMPLETO: De Principiante a Front-End**
https://www.youtube.com/watch?v=TlJbu0BMLaY

Colores, box model, Flexbox y diseño responsivo. Refuerzo entre la Clase 03 (CSS) y la Clase 04 (JS).

### JavaScript — Clase 04
**Introducción a la programación con JavaScript**
https://www.youtube.com/watch?v=Z34BF9PCfYg

Fundamentos de programación con JS: variables, tipos, funciones y lógica. JavaScript es el tema que
más práctica extra necesita, así que este video es especialmente importante verlo completo.

## ⚛️ Frameworks modernos (Clases 10–11) — React, Next.js, NestJS

Después de dominar lo vanilla, cada equipo decide si adopta un framework (ver
[../proyecto-de-equipo/ELEGIR-STACK.md](../proyecto-de-equipo/ELEGIR-STACK.md)). Para profundizar:

- **React** — documentación oficial (con tutorial interactivo): https://react.dev/learn
- **Next.js** — curso oficial "Learn": https://nextjs.org/learn
- **NestJS** — documentación oficial: https://docs.nestjs.com/
- **jscamp.dev** (abajo) cubre React y Node en español, ideal como refuerzo principal.

> Estas dos clases son una **introducción para decidir**; quien elija framework sigue aprendiendo por
> su cuenta con estos recursos. Requieren internet: verlos en casa o donde haya buena conexión.

## 🏕️ Bootcamp completo (transversal a todo el curso)

**jscamp.dev — Bootcamp Full-Stack de JavaScript (midudev)**
https://www.jscamp.dev/

Curso gratuito y en español que cubre HTML, CSS, JavaScript, Node.js, bases de datos y más, con
proyectos reales. Sirve como refuerzo durante **todo** el curso, no solo una clase. Recomendado para
los estudiantes que quieran profundizar o que vayan más rápido.

> Nota: para ver los videos y jscamp.dev se necesita internet. Como en el aula el internet es malo,
> estos recursos son para que los vean **en casa o donde tengan buena conexión**, entre clases.

---

## 🚀 Desplegar gratis

**free-for.dev — servicios con capa gratuita para desarrolladores**
https://free-for.dev/

Lista enorme y mantenida por la comunidad de servicios gratis: hosting de sitios y apps, bases de
datos, dominios, CI/CD, correo, monitoreo y más. Es la **referencia oficial del curso** para elegir
dónde desplegar cada proyecto. Cómo lo usamos, paso a paso, está en
[../DESPLIEGUE-CICD.md](../DESPLIEGUE-CICD.md).

> Regla rápida: solo frontend → hosting estático (GitHub Pages/Netlify/Vercel); con servidor Node →
> hosting de apps (Render/Railway/Fly.io). Todo se encuentra en free-for.dev.

## 🧭 Cómo usar estos recursos (para el instructor)

- Al cerrar cada clase de fundamentos, comparte el enlace del tema (queda escrito en el `actividad.md`
  de esa clase).
- Pide una **evidencia sencilla** de que lo vieron: una nota de 3 aprendizajes en su `notas.md`, o un
  mini-ejercicio del video. Así el refuerzo no queda en el aire.
- Los estudiantes que dominan rápido pueden avanzar en jscamp.dev mientras el resto refuerza.
