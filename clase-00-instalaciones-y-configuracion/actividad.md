# Actividad — Clase 0 (completar antes de la Clase 01)

**Objetivo:** dejar tu equipo 100% listo para programar. Lo que no se alcanzó en clase (sobre todo lo
que necesita internet), complétalo en casa o donde tengas buena conexión.

**Se entrega:** una captura o evidencia de que cada punto quedó listo (el checklist marcado).

---

## Parte A — Verifica tus instalaciones
En la terminal, ejecuta y confirma que responden con un número:
```bash
node --version
npm --version
git --version
opencode --version
```
Si alguno falla, revisa la [GUIA](GUIA.md) (sección correspondiente) o pídele ayuda a tu equipo.

## Parte B — GitHub
1. Crea tu cuenta en `github.com` (si no la tienes).
2. Con correo institucional del SENA, solicita el **GitHub Student Developer Pack** en
   `education.github.com` (da dominio gratis y créditos; se demora unos días en aprobar).

## Parte C — Configura tu identidad de Git
```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tucorreo@ejemplo.com"
```
Verifica con:
```bash
git config --global user.name
git config --global user.email
```

## Parte D — Tu primera conversación con la IA
Abre el asistente (OpenCode) y hazle **dos** preguntas:
1. "¿Qué es HTML y para qué sirve? Explícamelo como a un principiante."
2. "Dame 3 consejos para aprender a programar desde cero."

Escribe en un archivo `notas-ia.md` **qué te respondió** y **si te sirvió**.

## Parte E — Lee las reglas de oro
Relee la sección 7 de la [GUIA](GUIA.md) ("Cómo usar la IA sin dejar de aprender"). En `notas-ia.md`,
responde: **¿por qué no conviene pegar código que no entiendes?**

---

- [ ] Los 4 comandos de la Parte A responden en tu equipo.
