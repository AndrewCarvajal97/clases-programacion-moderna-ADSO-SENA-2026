Herramienta · runtime

Node.js

¿Qué es?

Permite ejecutar JavaScript fuera del navegador (en tu máquina, como servidor).

¿Por qué?

Es la base del backend del curso y trae npm para instalar librerías.

Instalar + verificar

Instala la versión LTS. Luego:

node --version
npm --version

⚠️ Sin permisos de administrador en el aula: usa la versión portable de Node.

Varias versiones de Node

pnpm también administra Node 🎯

¿Por qué?

Distintos proyectos piden distintas versiones de Node (uno la 18, otro la 20). Antes se usaba nvm… pero pnpm ya lo hace por ti.

pnpm = paquetes + Node

El mismo pnpm instala y cambia la versión de Node. Un solo gestor para todo.

PowerShell
PS> pnpm env use --global lts
# instala y activa la LTS
PS> pnpm env use --global 20
PS> pnpm env list
node v20 ✔

🆕 La forma más nueva: pnpm runtime set node lts -g. (nvm sigue existiendo como alternativa.)

📦 GESTORES DE PAQUETES

¿npm, pnpm, yarn o bun?

Todos instalan las librerías de tu proyecto. Se diferencian en velocidad, espacio en disco y seguridad.

npm

El que viene con Node. Confiable, pero más lento y gasta más disco.

pnpm ⭐

Rápido, ahorra disco (guarda 1 sola copia) y es estricto/seguro.

yarn

Alternativa popular a npm, similar en la práctica.

bun

Muy rápido y nuevo; también es un runtime. Aún con detalles de compatibilidad.

👉 En el curso usamos pnpm: más rápido, más seguro y ligero. Se activa así: corepack enable pnpm

Herramienta · versiones

Git

¿Qué es?

Guarda toda la historia de tu código y te deja volver a cualquier punto. Corre en tu máquina.

Configurar identidad

git config --global user.name "Tu Nombre"
git config --global user.email "correo"

Verificar

En la terminal:

git --version

Responde un número = listo.

Herramienta · editor

Visual Studio Code

¿Qué es?

El editor de código donde escribiremos todo. Gratis y muy usado en la industria.

Truco: code . abre VS Code en la carpeta actual.

Extensiones útiles 🧩

  • Live Server — ver tu HTML con recarga automática.
  • Prettier — ordena el código solo.
  • Español — la interfaz en español (opcional).
🔑 CUENTA

GitHub

¿Qué es?

Un servicio en la nube que aloja tus repositorios para compartir, trabajar en equipo y desplegar. Cuenta obligatoria.

Crea tu cuenta en github.com con un usuario profesional.

🎓 Student Pack

Con correo institucional, pide el GitHub Student Developer Pack en education.github.com: dominio gratis 1 año, créditos y más.

⚠️ ¿NO TIENES CORREO SENA?

Sin correo institucional… no hay problema

Si el SENA aún no te habilitó el correo, igual puedes trabajar. Tienes opciones:

① Verifica con documento

El Student Pack se puede pedir subiendo foto del carnet o una constancia de estudio del SENA — no solo con correo.

② No te bloquea

GitHub es gratis igual. Publicas en usuario.github.io sin dominio propio. El Pack lo pides después.

③ Agrégalo luego

Cuando te habiliten el correo, lo añades a tu cuenta de GitHub y solicitas el Pack en ese momento.

Para el asistente de IA y los despliegues no necesitas correo institucional.

🤖 ASISTENTE DE IA

OpenCode — instalar

¿Qué es?

Un agente/chat en la terminal que explica, sugiere y hace cambios en tu código. Open-source.

Como ya tenemos pnpm, lo instalas así 👉

🔜 Módulo futuro: modelo local (offline) en un server propio.

PowerShell
PS> pnpm add -g opencode-ai
… instalando paquetes …
✔ opencode instalado
PS> opencode --version
0.x.x

  • Explicar: "¿qué hace esta línea?"
  • Crear: "hazme un formulario de login"

Recuerda: entiende lo que te da; no lo pegues a ciegas.

La TUI

Comandos dentro de OpenCode

Escribe / y aparecen los comandos. Los que más usarás:

  • /init — analiza el proyecto y crea AGENTS.md
  • /connect — conectar el modelo (API key)
  • /help — ver todos los comandos
  • /undo — deshacer cambios (repetible)
  • /redo — rehacer
  • /share — link para compartir la sesión
🧭 DOS MODOS

Build vs Plan (tecla Tab)

📋 Plan

Solo propone y explica, NO toca tus archivos. Ideal para aprender: "¿cómo harías esto?".

🔨 Build

Sí hace los cambios en el código. Para cuando ya entendiste y quieres que lo haga.

Cambias de modo con Tab (el modo actual se ve abajo a la derecha).

Sacarle provecho

Contexto, tokens y deshacer

AGENTS.md

Un archivo (lo crea /init) que le explica tu proyecto. Súbelo a Git para que todo el equipo comparta el contexto.

Ahorrar tokens 💸

En el tier gratis: sé claro y concreto. Abre una sesión nueva al cambiar de tema (limpia el historial).

Sin miedo

/undo revierte lo que haga. Prueba tranquilo.

🔜 Para explorar después (video/docs): agentes, comandos propios, compartir sesión, conectar tu suscripción, skills.
