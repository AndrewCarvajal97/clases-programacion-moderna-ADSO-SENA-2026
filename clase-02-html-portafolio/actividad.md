# Actividad — Clase 02 (HTML)

**Objetivo:** dejar tu **portafolio v1** completo con contenido **real** (solo HTML, sin CSS todavía).
**Tiempo estimado:** 45–60 min.
**Se entrega:** el `index.html` en tu repo, con un commit.

---

## Parte A — Completa tu portafolio con TU información
Toma la plantilla y reemplaza todo el texto de ejemplo por lo tuyo:

1. Tu **nombre** real en el `<h1>`.
2. Un párrafo de verdad en **Sobre mí**.
3. Al menos **3 habilidades** en la lista.
4. La sección de **contacto** con tu correo.

## Parte B — Suma etiquetas nuevas (investiga)
Agrega al menos **dos** de estas etiquetas a tu portafolio y observa qué hacen:

- `<strong>` (negrita con énfasis) y `<em>` (cursiva con énfasis).
- `<a href="tu-github">` con el enlace real a tu GitHub.
- `<img src="..." alt="...">` con una imagen (puede ser un avatar).
- `<hr>` (línea separadora) o `<br>` (salto de línea).

> Si te atascas, pregúntale al **asistente de IA**: *"¿Qué hace la etiqueta `<strong>` en HTML? Dame un
> ejemplo."* — pero recuerda: **entiende** lo que agregas, no solo lo pegues.

## Parte C — Guarda en Git
```bash
git add .
git commit -m "Completa portafolio v1 con contenido real"
```
