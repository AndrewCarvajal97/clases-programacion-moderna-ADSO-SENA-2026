Concepto

¿Qué es CSS?

Si HTML es el esqueleto, CSS es la ropa y el maquillaje: colores, tamaños, espacios y dónde se coloca cada cosa.

🎨 Estilo, no estructura

Cascading Style Sheets. El HTML dice qué es; el CSS dice cómo se ve.

👕 Analogía

El mismo cuerpo (HTML) con distinta ropa (CSS) se ve totalmente diferente. Cambias el CSS y cambia todo el look.

🔌 3 FORMAS

Cómo se conecta CSS al HTML

1 · Inline
en el atributo style del elemento
evítalo
<p style="color:red"> — se desordena rápido.
2 · Interno
dentro de <style> en el head
ok para pruebas
<style> p { color: red } </style>
3 · Externo ⭐
archivo styles.css aparte
lo que usamos
<link rel="stylesheet" href="styles.css"> — ordenado y reutilizable.
Anatomía

Partes de una regla CSS

p { color: blue; }

Selector

A qué elemento(s) le aplico el estilo.

Propiedad

Qué quiero cambiar (color, tamaño…).

Valor

El valor concreto. Termina en ;

Selectores

¿A quién le aplico el estilo?

Por etiqueta

p { color: gray }

Todos los <p>.

Por clase .

.card { padding: 1em }

Los que tengan class="card".

Por id #

#logo { width: 80px }

El elemento con id="logo".

💡 La clase (con .) es la que más se usa: reutilizable y flexible.

🔗 COMBINADORES

Seleccionar por relación

A B — descendiente

.nav a { … }

Las <a> dentro de .nav (a cualquier nivel).

A > B — hijo directo

.lista > li { … }

Solo los li hijos directos.

A + B — hermano siguiente

h2 + p { … }

El p que va justo después de un h2.

A ~ B — hermanos siguientes

h2 ~ p { … }

Todos los p hermanos que sigan al h2.

✨ PSEUDOCLASES

Seleccionar por estado o posición

Empiezan con : y apuntan a un estado o una posición.

Estado

a:hover   /* mouse encima */
input:focus /* activo */

Posición

li:first-child
li:last-child
li:nth-child(2)

Negación

p:not(:last-child)
/* todos menos el último */

También existen los pseudo-elementos con :: — ::before y ::after crean adornos.

⚖️ ESPECIFICIDAD

¿Quién gana si hay varias reglas?

El navegador suma "puntos". Gana el selector más específico:

etiqueta
0,0,1 < .clase
0,1,0 < #id
1,0,0 < style=""
en línea < !important

Ej.: .proyecto.destacado (2 clases) le gana a .proyecto (1 clase).

💡 Consejo: usa clases. Evita #id e !important para estilos (rompen el orden).

Herencia

Propiedades que se heredan

✅ Se heredan

Del padre a los hijos, sin repetir: color, font-family, font-size, line-height.

body { color: white; }
// todos los textos heredan blanco

❌ No se heredan

Los de "caja": margin, padding, border, width, background.

Por eso en el portafolio el color se pone una vez en body. Con inherit puedes forzar la herencia.

Herencia · a fondo

Valores especiales de herencia

inherit

Fuerza heredar del padre.

initial

Vuelve al valor por defecto de la propiedad.

unset

Hereda si es heredable; si no, initial.

revert

Vuelve al estilo del navegador.

🛟 FALLBACKS

Planes B por si algo falla

Fuentes

font-family:
  "Sora", system-ui, sans-serif;

Si la 1ª no carga, usa la siguiente.

Variables

color: var(--x, #eee);

Si --x no existe, usa #eee.

@supports

@supports (backdrop-filter:blur(1px)) { … }

Aplica solo si el navegador lo soporta.

Los fallbacks hacen que tu página no se rompa en navegadores viejos.

💧 LA "C" DE CSS

¿Qué es la cascada?

CSS = Cascading Style Sheets. Si varias reglas afectan lo mismo, el navegador decide cuál gana en este orden:

1. Importancia

!important gana (evítalo).

2. Especificidad

Más específico gana (id > clase > etiqueta).

3. Orden

Si empatan, gana la última regla escrita.

Por eso el orden importa: lo de abajo puede sobrescribir lo de arriba.

Colores

Colores 🎨

#38bdf8 #a78bfa #4ade80 #fbbf24 rgb(244,114,182)

Por nombre

red, blue, tomato…

Hex

#38bdf8 — mezcla de rojo, verde y azul.

RGB

rgb(56,189,248) — lo mismo, en números.

color = texto · background-color = fondo.

Tipografía

Tipografía y fuentes 🔤

body {
  font-family: system-ui, sans-serif;
  font-size: 16px;
  line-height: 1.5;
}
h1 { font-weight: 800; }

Propiedades

font-family (tipo de letra), font-size (tamaño), font-weight (grosor), line-height (interlineado).

⚠️ Sin internet

Usa fuentes del sistema (system-ui, Arial). Para una fuente propia offline: @font-face con un archivo de fuente local.

📏 UNIDADES

Absolutas vs relativas

Absolutas

px — píxeles fijos. Precisas, pero no se adaptan.

Relativas ⭐

  • % — respecto al padre.
  • em — respecto a la fuente del elemento.
  • rem — respecto a la raíz (la mejor para tamaños).
  • vw / vh — % del ancho / alto de la pantalla.

Para diseños que se adaptan, prefiere rem, % y clamp() sobre px.

📦 EL BOX MODEL

Toda etiqueta es una caja

margin — espacio POR FUERA
border — el borde
padding — espacio POR DENTRO
CONTENIDO
margin — separa la caja de las de al lado (por fuera).
border — la línea del borde.
padding — aire entre el borde y el contenido (por dentro).
content — el texto o la imagen.
Modelo de caja · truco clave

box-sizing: border-box

Por defecto, el padding y el border agrandan la caja. Con border-box, el ancho que pones es el ancho final.

* { box-sizing: border-box; }  /* se pone una vez, al inicio */

Es el primer "reset" que casi todos aplican: hace el tamaño predecible.

Bordes

border vs outline

border

Ocupa espacio (es parte de la caja). Cada lado se configura.

outline

No ocupa espacio (se dibuja por fuera). Ideal para el foco de accesibilidad.

Cuando el contenido no cabe

Overflow y text-overflow

overflow

visible (se sale), hidden (se corta), scroll/auto (barra).

Texto con "…"

white-space:nowrap;
overflow:hidden;
text-overflow:ellipsis;
📌 POSITION

Colocar elementos

  • static — normal (por defecto).
  • relative — se mueve respecto a su lugar; sirve de "ancla".
  • absolute — respecto al ancestro con position.
  • fixed — fijo en la pantalla (no se va con el scroll).
  • sticky — normal, pero se "pega" al hacer scroll.

Con top / right / bottom / left ajustas la posición.

Capas

z-index: quién va encima

Cuando dos elementos se superponen, el de mayor z-index va delante.

.modal { position:fixed; z-index:100; }

Solo funciona en elementos con position (no static).

Punto de partida

Reset y Normalize

Cada navegador trae estilos por defecto distintos. Para partir parejo:

Reset mínimo

* {
  margin:0; padding:0;
  box-sizing:border-box;
}

Normalize.css

Una hoja que empareja los estilos entre navegadores (en vez de borrarlos del todo).

🧲 FLEXBOX A FONDO

Todas las propiedades de Flexbox

En el contenedor

  • flex-direction — row / column
  • flex-wrap — que bajen de línea
  • justify-content — eje principal
  • align-items — eje cruzado
  • gap — separación

En cada hijo

  • flex-grow — crecer
  • flex-shrink — encoger
  • flex-basis — tamaño base
  • order — cambiar el orden

Atajos: flex: 1 (grow/shrink/basis) · flex-flow (direction + wrap).

▦ GRID

CSS Grid: rejillas en 2D

Flexbox acomoda en una dirección (fila o columna). Grid acomoda en dos a la vez: filas y columnas. Es lo mejor para layouts.

Flex → 1D

Una fila o una columna.

Grid → 2D

Una cuadrícula (filas y columnas).

Grid en código

Columnas y la unidad fr

.rejilla {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;  /* 3 columnas iguales */
  gap: 1rem;
}

fr = "fracción" del espacio libre. 1fr 2fr = la 2ª el doble de ancha.

Grid responsivo

repeat() y auto-fit

grid-template-columns:
  repeat(auto-fit, minmax(200px, 1fr));

Crea tantas columnas como quepan (mínimo 200px) y se reacomodan solas en el celular. ✨

Es la línea mágica para galerías y tarjetas responsivas — ¡sin media queries!

Layouts con Grid

grid-template-areas

grid-template-areas:
  "header header"
  "aside  main"
  "footer footer";

Dibujas el layout con palabras y asignas cada zona con grid-area. Muy legible.

✨ CSS MODERNO

Anidamiento con &

Puedes anidar reglas dentro de otras con & (nativo en navegadores modernos).

.card {
  padding: 1em;

  &:hover {          /* estado */
    transform: translateY(-4px);
  }
  & h3 {            /* subelemento */
    color: blue;
  }
  &.destacada {      /* subclase */
    border: 2px solid gold;
  }
}

&:hover

Un estado, anidado dentro.

& h3

Un subelemento de la tarjeta.

&.destacada

Una subclase (variante).

Más limpio: todo lo de .card en un solo bloque. Así está el styles.css del portafolio.

🎬 TRANSICIONES

Transiciones: cambios suaves

Animan el cambio entre dos estados (ej. al :hover).

.boton {
  background: blue;
  transition: background .3s ease;  /* qué, cuánto, cómo */
}
.boton:hover { background: coral; }

⚠️ Evita transition: all (anima de más y va lento). Anima solo lo que necesitas.

Animaciones

@keyframes: tu propia animación

@keyframes aparecer {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; }
}
.tarjeta { animation: aparecer .6s ease both; }

Atajo animation: nombre, duración, curva, repeticiones, y animation-fill-mode (both mantiene el estado final).

🆕 SCROLL · FPS

Scroll y rendimiento

Lo más nuevo: animar según el scroll con CSS puro (animation-timeline: view()).

⚡ Rendimiento (60 FPS): anima transform y opacity (son las más rápidas). Evita animar width, height o margin (obligan a recalcular todo).

El scroll con CSS aún no funciona en todos los navegadores → en el portafolio lo hacemos con JS (IntersectionObserver, Clase 04) para máxima compatibilidad.

📱 RESPONSIVE

Que se vea bien en el celular

Una media query aplica estilos solo cuando la pantalla es de cierto tamaño.

/* cuando el ancho sea 600px o menos (celular) */
@media (max-width: 600px) {
  .menu { flex-direction: column; }
}

💡 Pruébalo en el navegador: F12 → modo celular, y ve cómo cambia.
